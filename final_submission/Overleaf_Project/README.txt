Springer Nature / BMC Biomedical Engineering Overleaf project

Upload the contents of this folder, or the accompanying Overleaf ZIP, to a new
Overleaf project. Set main.tex as the main document and compile with pdfLaTeX.
The required Springer Nature class and Vancouver bibliography style are included.

Files
-----
main.tex                 Manuscript source
references.bib           BibTeX database
sn-jnl.cls               Official Springer Nature class (December 2024 release)
sn-vancouver-num.bst     Official Springer Nature Vancouver style
*.png                    All manuscript figures, including actual final MuJoCo frames
main.pdf                 Locally compiled and visually checked reference PDF

Before submission
-----------------
The source currently identifies the author as an independent researcher in the
United States because no institutional affiliation or corresponding email was
provided. Replace that affiliation and add the preferred correspondence email
in main.tex if different. Also enter the corresponding author details and the
two supplementary ZIP files in the BMC submission system.

The manuscript is formatted as a BMC Biomedical Engineering Research Article:
structured abstract, line numbers, double spacing, Vancouver references, figure
captions, and complete declarations. The source data and analysis package are
cited in the Availability of data and materials section.
